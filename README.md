# **中国人民警察宣誓**

---

> **我宣誓：**  
> 坚决拥护**中国共产党**的绝对领导，  
> 矢志献身崇高的**人民公安事业**，  
> 对党忠诚、服务人民、  
> 执法公正、纪律严明，  
> 为捍卫政治安全、维护社会安定、保障人民安宁而英勇奋斗！

- **对党忠诚**
